# Alice Mini App

مینی‌اپ فارسی مجموعه ورزشی آلیس، در همان پروژه بات.

## اجرا و داده‌ها

- رابط مشتری: `app/page.tsx`، متناسب با Telegram Mini Apps و مرورگر موبایل.
- محتوا: `GET /api/content` از D1 با داده اولیه بدون قیمت یا سانس ساختگی.
- انتشار محتوا: `PUT /api/content` با کلید محرمانه `ALICE_CONTENT_KEY`؛ کلید در مرورگر قرار نمی‌گیرد.
- ویرایش محتوا: پنل محلی بات در `/miniapp` روی پورت 8765. این پنل با همان رمز مدیریت محافظت می‌شود.
- کلید انتشار در `.dev.vars` برای توسعه محلی و در متغیرهای محرمانه Sites برای انتشار نگهداری می‌شود.
- توکن تلگرام فقط در پروژه اصلی بات می‌ماند و در این پروژه منتشر نمی‌شود.
- مشتری به حساب کاربری نیاز ندارد؛ تنظیم دسترسی عمومی صفحه جدا از حفاظت مسیر ویرایش است.

تغییر سانس‌ها، تعرفه‌ها، قوانین، نشانی و اطلاعیه‌ها از پنل انجام می‌شود؛ اطلاعات در D1 پایدار می‌ماند. هنگام انتشار ناموفق، نسخه ویرایش‌شده در پوشه داده محلی بات محفوظ است. بازکردن دوباره صفحه یا دکمه تازه‌سازی آخرین اطلاعات را دریافت می‌کند.

نسخه اول شامل رزرو، پرداخت، عضویت یا ثبت اطلاعات شخصی مشتریان نیست.

## توسعه

`npm run dev` پیش‌نمایش را اجرا می‌کند. `npm run db:generate` پس از تغییر schema مهاجرت تولید می‌کند. مهاجرت‌های اعمال‌شده را تغییر ندهید. خروجی انتشار از workflow ابزار Sites تولید می‌شود.
